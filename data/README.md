# ゲーム用定義

このディレクトリはGit管理対象。画像・音声の実体はGit対象外の `assets/` に置く。

- `characters/`、`supports/`、`demos/`、`stages/`、`system/`：実行用のスクリプト・素材一覧・設定。
- 各 `data.lton`：抽出した設定情報。変換・調査用で、ゲーム配布には含めない。
- `_conversion/`：共有化の再生成に使う `support-source.lton`。実行時には読まず、配布にも含めない。

`images.lton` / `sounds.lton` の `file` は対応する `assets/` 内のフォルダからの相対パス。
`shared` は `assets/shared/` からの相対パス、`asset` はゲームルートからのパス。
定義を移動しても画像・音声の参照先は変わらない。

実行コードは素材フォルダをパッケージの識別に使い、`vp.resource` がLTONの読み込み先を `assets/` から `data/` に解決する。
古い場所へのフォールバックは行わない。

生成ツールは従来の `assets` 引数を受け付け、定義の出力先を隣の `data` に解決する。
再生成前にGit差分を確認すること。生成処理は編集内容を上書きするため、恒久的な変換修正はツール側にも反映する。
旧 `assets/**/skills/NNNN.lton` は比較資料として残しているが、実行・再生成の入力には使わない。
原作の調査には未加工JSON、元のFM2Kファイル、原作実行時の挙動を使う。
