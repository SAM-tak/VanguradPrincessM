# 0006: FM2K の組み込み部分（エンジン側）の挙動 — ジャンプと攻撃

- **日付**: 2026-09-28
- **状態**: ゆいでジャンプ 3 種・地上/しゃがみ/空中の A・B・C が動作

FM2K のキャラデータは「技」の集まりで、どの技をいつ始めるかの一部はエンジンが決める。
移植版では `main.lh` の `control` がその役（キャラ設定の組み込み技番号とコマンド表をもとにする）。

## データから読み取った約束

- **ジャンプの技（#4 垂直 / #5 前 / #6 後）は踏み切った直後に `E` で終わる。**
  空中で技が終わったら、エンジンが**落下の技（#7）**に移す。
  #7 は変数（キャラ A = 50 / 60 / 70）を見て、元のジャンプ技の後半（#4:22 など）の上昇・下降の絵へ飛ぶ
- **速度は技をまたいで保たれる。** #7 の M は「速度はそのまま、重力だけ設定」（keepVX / keepVY）
- **着地は DS（イベント登録）で決まる。** #7 は「着地したら #9」、空中攻撃は「着地したら #8:15」や「#10:57」を登録する
- 対象の無い DS は「そのイベントの登録を外す」
- 空中攻撃は、終わった時点でまだ空中なら落下（#7）へ移る

## 移植版での扱い（`src/fighter.lh`）

- `begin(n)` — エンジンが技を始めるとき（入力による開始、着地後の立ちなど）。
  攻撃判定・DS・タスク変数を消す。**地上なら速度も止める**（立ちの技は M を持たないので、止めないと滑る）
- `start(n, b)` — スクリプトのジャンプ（SG / V / Rnd などで別の技へ）と、エンジンの「空中で終了 → 落下」。
  判定・速度・変数・DS をすべて引き継ぐ
- `airborne()` — 足元が地面より上。着地の判定は「空中から地面に達した瞬間」

## 移動の単位と I の待ち時間（FM2K 本体の解析資料より、2026-09-28）

出典: FM2K ロールバックランチャー（Armonte/wanwan）の逆コンパイル解析
`docs/analysis/gamespeed_csm_decompile.md`（読んで理解したのみ。コードは流用していない）。
ゲーム速度が既定（10）のとき:

- **M の速度**は値 × 655 / 65536 px/フレーム（≒ 1/100）、**重力**は値 × 393 / 65536 px/フレーム²（≒ 1/167）。
  単位が違う。最初は両方 1/100 と置いていたためジャンプが低かった（高さ 130px → 正しくは約 218px）
- 左右の値の符号は **M ブロックを実行した時点の向き** で決まり、以後は世界座標の向きのまま（振り向いても速度は反転しない）
- 毎フレーム `位置 += 速度; 速度 += 加速度`。止める・反転を防ぐ処理は無い
- **着地したときは、横も含めて速度と加速度をすべて 0 にする**（逆コンパイルの着地処理より）。
  これを縦だけにしていたため、ピヨリ始動（#177: 後ろ上へ跳ね、横の摩擦 +6）の着地後に、残った摩擦で前へ滑り続けていた
- **I の待ち N は N+1 フレーム**表示する（0 なら待たない）。タイマーに 100×N を足し、毎フレーム 100 引き、負になったら次へ進むため
- 1 フレームに実行するブロックは最大 300 個（安全装置）

## 向き・振り向き・押し合い

- 練習相手として 2 体目のゆい（パレット 2、立っているだけ）を置いた
- 振り向きの技（#16 / #17）は中身が空。振り向きは向きの反転だけ。地上で自由に動ける技の間だけ、相手の方を向く
- 画像: 向きに合わせて左右反転。`turnX` / `turnY` でさらに反転、`ignoreDirection` なら向きを無視
- 判定の矩形も向きで反転する（中心 x に向きを掛ける）
- 押し合い: 地上どうしのとき、押し合い判定（FD collide）が重ならないよう半分ずつ押し戻す。
  空中では押さないので、ジャンプで相手を飛び越せる（前ジャンプで約 300px 進む）

## lhat について分かったこと

- **`def^` の中で、後に定義されたメソッドを呼ぶと、無関係な誤りになる。**
  `play` から後ろの `airborne` を呼ぶと `require^"sprite.lh"` の行で
  「this name is already defined in this scope: sprite」。`airborne` を前へ移すと通る
- 配列の添字の答えは `T|nil^`。そのまま `number^` の引数に渡せないので `?? 既定値` を付ける
