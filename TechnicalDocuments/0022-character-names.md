- **日付**: 2026-10-04
- **状態**: 適用済み

## 正式名

原作のファイル（.player）はキャラの内部名で付いている。移植では正式名を使う（ユーザー決定。内部名だと混乱するため）:

- ついん → **えり**
- みさき → **サキ**
- ゆかり → **はるか**
- みこ → **あやね**
- 他（ゆい、リリス、ルナ、くるみ、かえで、カテジナ、ヒルダ、だみー）は内部名 = 正式名

- 表は `tools/fm2k_convert/names.py`（`OFFICIAL`）。convert.py はキャラのフォルダと、システムの data.lton のキャラ一覧（`characters`）を正式名で書く
- `src/select.lh` の CHARACTERS、`share_owners.txt` の持ち主も正式名
- **それ以前の技術メモ（0001〜0021）は内部名のまま**（日付付きの記録として残す）。デモの名前（「ランダムみさき」など）はデモのファイル名なので変えない

## 未使用キャラ（new1、新2）

- 原作のキャラ一覧にあるが中身が無い（画像 0 枚。新2 は音 1 個だけ）。参照はシステムのキャラ一覧だけ
- convert.py は変換しない（`names.UNUSED`）。assets からフォルダを消した
- **一覧の名前は残す**: 消すと後ろの だみー（ストーリーモードの難易度選択・ロード中画面に使われているとみられる。ユーザー）の番号がずれるため
