# デモ対戦で1P名がゆいになる問題

システムのHUDスキル59は変数129を100〜1000のキャラ番号として判定し、対応する名前画像を表示する。どの条件にも一致しない場合は先頭のゆい画像241へ進む。

原作の1P番号はキャラセレの各キャラのスキル25が設定する。一方、2P番号の変数130は各キャラの開始スキル21でも設定する。デモ対戦はキャラセレを経由せずシステム変数をクリアしていたため、1P番号だけが未設定の0になった。サポート番号142／143はデモ初期化時に設定していたため正常だった。

`startRound` で実際の両Fighterのキャラを番号に変換し、HUDを起動する前に129／130を設定する。番号はキャラセレの順番×100、ボスのヒルダは1100。デモだけでなく通常対戦・ストーリー・次ラウンドでも同じ初期化を使い、キャラセレの実行済み状態に依存させない。

`attract-flow` に、実際の1Pキャラと変数129・HUDスキル59の表示画像が一致することの検証を追加。
