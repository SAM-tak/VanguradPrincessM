# 0018: コンボ表示（HIT COMBO）

- **日付**: 2026-10-03
- **状態**: 2 ヒット目から「n HIT COMBO」が出る。位置・出方は原作のメモリを読んで合わせた

## 素材と技

- システムの組み込み技 **#1「ヒット文字 HIT」**（画像 261 =「HIT COMBO」の帯。0011.png と同じ絵）と、
  **#2〜#11「ヒット数字 0〜9」**（青い数字: 0 = 15、1 = 16、2 = 12、3 = 13、4 = 14、5〜9 = 17〜21。
  赤い版 29〜39 はシステム変数 128 = 1 のときの分岐）
- 位置を決める設定（「位置：…」の技）は無い。**エンジンが置く**
- キャラの #798「ヒット数」は表示ではない（画像は y 1000 の画面外。キャラ変数 72 / 76 を見る状態機械）

## 原作で測ったこと（VS モード、ゆい 対 ゆい、オブジェクトの一覧 0x4701E0 を読んだ）

- 2 ヒット目で、#1 と数字（#2 + 数）が**同じ位置**に出る（種類 2 = システムのオブジェクト、深さ 101、**ワールド座標**）
- **位置 = 受ける側の位置 + 当たったやられ判定（FD）の x, y**（x は向きで反転）。判定の中心ではなく FD の x, y そのもの
  - しゃがみ A ×2 → #47 の FD 3（1, −17）: 表示 (908, 903)、受ける側 (911.9, 920)
  - 天雷の 2 ヒット目 → #159 の FD 1（−9, −91）: 表示 (1239, 718)、壁際の受ける側 (1230, 802.8)。
    y は落下中のため、そのフレームの移動前の高さ（≈ 809）から −91
- 3 ヒット目は**新しい組をもう一つ出す**。古い組は消さず、それぞれの技の終わりまで残る（#1 は約 0.55 秒、数字は約 0.75 秒）
- 受ける側が立ち（#1）に戻ると次の攻撃は 1 ヒット目から
- 親は当てた側（キャラ本体か、当たったオブジェクト）

## 実装

- `main.lh` の `strike`: ガードされなかったら受ける側の `combo` を足し、2 以上なら `vp.round.showCombo`
- 受ける側が自由に動ける技（立ち・歩き・しゃがみ・ジャンプ）にいたら `combo` を 0 に戻す
- `src/round.lh` の `showCombo`: #1 と、数の各桁の数字をワールド座標で走らせ（深さ 101）、
  描画はビュー座標の段でカメラ分ずらす
- **未計測**: 10 ヒット以上の桁の並び。十の位を一の位の 30 px 左に置いた（仮）。ガードを挟んだときの数え方
