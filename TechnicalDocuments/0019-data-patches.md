## 仕組み

- 原作どおりに再現するのが基本だが、意図して変えるデータもある（修正、ユーザーが選んだ改良、キャラ間で共有する素材など）
- **`assets/` を手で直さない**（変換し直すと消える）。`tools/fm2k_convert/patches/<JSON の stem>.py` に、
  fm2ndparser の JSON を書き換える `patch(d)` を置く
- `convert.py` と `gen_script.py` は JSON を読んだ直後に `patches.apply(path, d)` を呼ぶ → LTON・スクリプト・素材のどれにも同じ変更が入る
- 補助: `patches.renumber(blocks)`（ブロックを足したり動かしたりした後の index の振り直し）
- 予定: サポートキャラの絵・音声を括り出して全キャラで共有する（ユーザーの次の作業）

## 差し替え 1: キャラ選択の幕（`patches/キャラセレ.py`）

- モード選択 → キャラ選択で黒い画面を挟むのは、デモ「キャラセレ」のレイヤー #31「スクリプト1」の幕:
  背景（画像 0）を全体に重ねて、`COLOR 0, 224`（色補正 −32 = 黒）から 5 フレーム、明るくしながら 2 フレームずつ、
  そのまま 3 フレーム、`COLOR 4` で透明にしながら 8 フレームで消える（E）。約 0.26 秒
- 原作にもある。黒いのは最初の 6 フレーム（約 60ms）だけで、原作の録画では見えなかった（覆っている段階は見える: 立ち絵が隠れ背景だけになる）。
  移植版で黒が長く見えるのは、選択画面の最初の描画で画像を初めて読むため（最初の描画 124ms）
- #31 は `ｼｽﾃﾑｲﾒｰｼﾞ位置` より後ろ → 奥行き 100。カーソル（101）と矢印（127）が黒の上に出る。原作も同じ（録画でも幕の上に出ている）
- **変更**（ユーザー判断: 黒を挟むのは改良として残し、幕をカーソルより手前に）:
  幕の中身を空きの #32 に移し、#31 はそれを `point` 奥行き 127 の O で出して E で終わる。
  #32 は名前が空のまま → レイヤーにはならない（`vp.script.layers` は名前のある技だけ）
