# ESCの適用範囲と開発用F8

- ゆい勝ちデモ中のESCは無視する。全キャラ共用の勝利デモなので、勝者によらず適用。通常の決定ボタンによる進行は維持する。
- pendingロード、VSロード演出、ロード後の登場処理の追いつき中もESCを無視する。ロード待ちをポーズ扱いにしない。
- ポーズ判定は準備完了後の対戦状態に適用する。通常戦闘だけでなく、開始演出、KO、勝利ポーズ、ラウンド間も対象。ESC／Enter／パッドStartで切り替える。パッドBackはESCに割り当て済み。
- F8は開発用のタイトル復帰。入力処理の先頭で処理し、CPUデモ・ポーズ・ロード・ストーリーなどの通常操作制限より優先する。
- F8ではpending Batchをキャンセルし、システムアリーナ以外を破棄する。ロード済み常駐のタイトルを無音で表示し、対戦・ストーリー・CPUデモ・ポーズ・入力をリセットする。バックグラウンドのキャンセル済みジョブは通常pumpで回収する。
- 起動用の常駐素材がまだ読み込めていない場合のF8は、起動ロードの完了後にタイトル静止画へ入る予約にする。

検証：async-flowでロード中のESC無視、F8でロードキャンセル後の再入場、ポーズ中からのF8復帰を確認。story-flowで勝利デモ中のESCが画面遷移・ポーズを起こさず、通常の進行が続くことを確認。story-navigationのロード中ESCの期待値を、キャラセレへ戻る動作から無視へ変更。
