## 「未使用の重複」ではない

151枚中146枚は各所有キャラのえこ定義からI命令で参照される。残る5枚は本体に残る「うほえこ」(#784等)の画像2101〜2103として使われる。画像一覧にあるだけの未使用ファイルではない。

既存のassets/supports/えこ/imagesには93枚。比較対象151枚のうち同寸法の既存画像があるのは77枚、画素の完全一致は0枚。参照元キャラの全8パレットを用いた表示一致も0枚。既存93枚に対して同寸法のない74枚が、直ちに形の異なる新規アニメーションであるとまでは断定しない。

例: 013deafe...ddsと既存1310.ddsは511画素のインデックスが異なり、104〜108と23〜27の対応が見られる。共有側をあやねの標準パレット、既存側をゆいの標準パレットで描画すると完全一致する。一方、あやねのパレットで画像だけ既存側に置換すると511画素の色が変わる。これはヘッダ等の無意味なバイナリ差ではなく、キャラ固有パレットへの適合を含む差異である。

## 重複候補の自動調査

```
python tools/fm2k_convert/audit_support_images.py assets --support えこ --out build/eko-image-comparison.json
python tools/fm2k_convert/organize_support_media.py assets --owned-only --apply
```

監査ツールは読み取り専用。既存のPillow依存だけでDDSの展開画素を比較し、同寸法の番号付き画像を候補にする。各参照元キャラの8パレットで透明度と可視RGBを比較する。類似度が高いだけの画像は削除・置換しない。今回の安全な単純統合候補は0枚。

画像本体を更に共通化するには、パレットの色番号変換を画像ごとに保持する等の別設計が必要。今回の変更は配置と参照の整理であり、画像容量やロード対象の集合を削減するものではない。本体側の演出に残る画像も従来どおり先読みされる。
