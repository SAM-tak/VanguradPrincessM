# 0032: ゲームパッドと2P入力

- 日付: 2026-10-04
- ゲームパッド操作と、VSテスト用の独立した2Pキーボード操作を追加。

## 割り当て

| 操作 | 1Pキーボード | 2Pキーボード | パッド（Xbox表記） |
|---|---|---|---|
| 上・左・下・右 | ↑・←・↓・→ | U・H・J・K | 十字キー／左スティック |
| A | Z | L | A |
| B | X | ; | B |
| C | C | ' | X |
| D | A | O | Y |
| E | S | P | LB |
| F | D | [ | RB |

SDLのゲームパッドとして認識される機器を接続順に1P、2Pへ割り当てる。抜いた場合は保持状態を破棄し、残った機器のスロットは維持する。新しい機器は空きスロットに入る。3台目以降と、ゲームパッドマッピングを持たない汎用ジョイスティックは対象外。

左スティックの方向判定閾値は±0.35。十字キーとORで組み合わせる。攻撃・メニュー方向入力は押し始めだけ、移動・ガード・コマンド方向は保持状態を読む。キーボードとパッドの同じ攻撃ボタンが同じフレームに押されても、ビット加算で別ボタンにならないよう重複を抑える。

BackはESC相当。Startはメニューの決定相当（1P側）、試合中はポーズ／再開（[0033](0033-battle-pause.md)）。タイトル・難易度などの共通メニューは1Pが操作する。

## 実装

- `src/input.lh`: 接続管理、パッドの押下エッジ、キーボードとパッドの保持入力を統合。エンジンの変更は不要。
- `main.lh`: プレイヤー別の押下入力を受け取り、VSの2Pにも移動・技・後ろ方向のガードを適用。STORYの相手は引き続きCPU。
- `src/select.lh`: VSの両者は各自の入力で同時に選択可能。2Pが先に決定しても1Pが決定するまでロードを開始しない。STORYは1Pだけ。
- 2Pキーと重複する旧H/K/Lのデバッグ機能はF1（判定表示）、F2（相手HP=1）、F3（音声ログ）へ移動。
- 2Pの押下フラグは消費時、ロード完了、戻る操作、無関係な画面で消去し、次画面への持ち越しを防ぐ。
