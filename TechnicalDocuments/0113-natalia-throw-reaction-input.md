# 0113: ナタリアのコマンド投げ中の入力割り込み

2026-10-08。ロザリオンバスターの途中で相手が脱出できる問題。

## 原因

一回転A/B/Cはコマンド7/8/9から#237/#236/#235へ入り、成立時のDS attackingで#218へ進む。コマンド24/23/6は別の#273/#272/#271。

#218はRP104→RP102→RP103を実行する。ゆいでは#172→#45→#46となるが、#45と#46のSettingsはlevel=0。mayStartはレベル0を無条件で入力可能と扱い、receivingを確認していなかった。投げ途中にコマンド表から通常技を開始でき、空中でも専用やられ動作を失っていた。

修正前の#218直接実行では無入力時に#172→#45→#175→#46と進む一方、A連打では31tickの#45、69tickの#46から#213へ割り込んだ（build/rosarion-before.log）。

## 原作との照合と変更

原作EXEのRPは0x413139–0x413152で対象の状態に0x0Aを設定。0x411922–0x411934の入力処理は状態&0x0Cが8ならコマンド受付を飛ばす。技レベルとは別の被弾状態による制限。

Fighter.mayStartで、未終了のreceiving/blocking中はコマンド表による技開始を拒否する。正常終了後の受付は維持。COM命令はこの関数を経由せず、やられスクリプト内に設定された正規の受け身受付は変えない。技データの変更やナタリア専用例外は不要。
