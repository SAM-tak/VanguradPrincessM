# 連続ヒット数によるダメージ補正

2026-10-07。0088の低体力補正とは別に、settings.comboによる補正を実装。

## 原作の計算順序

`build/original-corner-disasm.txt` の `0x40F786–0x40F808`。攻撃側のプレイヤー設定combo（`+0x7CA8`）と被弾側のカウンタ（`+0xDF01`）を使う。0x40F786のesp+0x28は、直前の2回の呼出しで計16バイトの引数が残っているため、通常時のesp+0x18（攻撃側データのオフセット）に相当する。

非ガードかつFA威力が非0のとき、命中前のヒット数をnとする。

1. `base = max(power - floor(power * comboRate * n / 100), 1)`
2. `damage = max(floor(base * FD倍率 / 100), 1)`
3. 0088の低体力補正を適用し、HPを減らす。
4. 被弾側のヒット数を1増やす。

段階ごとに整数化する。一つの乗算へまとめない。例：威力101・comboRate8・既存1ヒット・FD150%は、101→93→139。さらに低体力85%なら118ダメージ。

ガード削り、FA威力0、生成物を殴った場合、GPによる体力変更はこのカウンタを進めない。攻撃が生成物の場合も、攻撃側本体のcomboRateを使う。別の攻撃元へ変わっても被弾側のカウンタは共有する。

`gen_script.py` / `gen_skills.py` に出力を追加し、本体12ファイルと変換中間物11ファイルの設定ヘッダーへ反映。技ブロックは変更しない。ボスヒルダのヘッダーには低体力設定も欠けていたため、抽出済みdata.ltonのstartPos20/correct99を併せて保存した。手続き生成側にも0088の低体力設定を追加した。

原作でDF01を0へ戻す箇所は初期化 `0x411F35` と、呼出し元への復帰先がない本体アニメーション終了 `0x412719`。`0x41266A–0x4126D9` のSC/SF復帰処理はそれより前に分岐している。

表示用comboとは別に `Fighter.damageHits` を保持する。本体の最上位スクリプトが終了した時点でリセットし、SCからの復帰、SG/DSによる継続、ヒットストップでは保持する。ラウンド再配置時にも0へ戻す。既存の表示用コンボ数や受け身可能コンボの赤表示は変更しない。SC/SFの複雑な分岐全般の互換性は別の残件。
