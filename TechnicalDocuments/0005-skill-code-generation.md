## 生成の方針

技 1 つ = `p^me:Fighter, at:number^`（at = 開始ブロック）。語彙は `src/fighter.lh`。

- **ジャンプ先が自分の先頭（ブロック 0）だけの技** → 素直な直線コード。先頭へ戻るなら `repeat^while^me.alive { … }`
- **それ以外**（技の途中へのジャンプがある、または他の技から途中に入られる）→ ブロック番号を `pc` に持つ状態機械:

  ```lhat
  var^pc = at
  repeat^while^me.alive {
      if^spin(me) { yield^ }
      if^pc = 0 {
          settings(me, 0)
          pc := 2
          if^v(me, 70) < 198 { pc := 3 }
      }
      if^pc = 2 { … }
      …
      if^pc < 0 { return^ }
  }
  ```

  ラベルは「ジャンプ先」と「条件ジャンプの直後」。後ろへのジャンプは、ループをもう一周して着く。
- **他の技へ**: SG → `jump(me, n, b)` + `return^`（fighter が同じフレーム内で切り替える）
- **呼び出し**: SC → `await^call(me, n, b)`、SF → `for^` で loop 回 `await^call`
- 他の技への参照はすべて**技番号で表を引く**（`me.skills[n]`）。モジュール間の循環 require を避けるため
- I ブロックが無く中断しない技は `_yield^` を置いて、型を他の技とそろえる（`c^{p^-> nil^}`）
- 画像を出さずに回り続けるループの保険として、状態機械の先頭に `spin(me)`（1 フレーム 256 周で待つ）

## ブロックの意味（コミュニティ資料「The Big FM2002 Community Compendium」より）

- **V**: `replace` / `add` で `value`（`useEven` なら別の変数の値）を代入・加算。
  `itsTheSame` / `itsAbove` / `itsBelow` で変数と `multiCondValue` を比べ、成り立てば `multiCondSkill` へ
  - 変数番号: 0〜16 タスク（技ごと）、64〜79 キャラ、128〜143 システム、192〜199 データ（x, y, 時間など）
- **Rnd**: 0〜Total−1 の乱数が `whenItsAbove` を超えたらジャンプ
- **SG** = go to、**SC** = call（呼んだ技の E で戻る）、**SF** = loop 回 call
- **DS**: この技の間、イベント（着地・攻撃ヒット・ガードされた・壁・オフセット・投げ成功）が起きたらジャンプ
- **O**: 技を走らせるオブジェクトを生成。parent で親に追従。「It's out」は生成後に本体が移る技
- **C**: キャンセル条件（ヒット時／無条件／失敗時、レベル範囲 from〜to、または特定の技へ）

意味が資料からはっきりしないもの（V の above/below の向き、SF が call か jump か）は、
語彙の手続きの中身で決める。生成コードの形には影響しない。

## lhat について分かったこと

- **`if^ … { … next^ }` がレジスタを解放しない。** 1 つのループ内で `next^` が 60 個ほどを超えると
  `too many registers or constants`（`LHAT_MAX_REGISTERS` = 250。1 個あたり約 4 レジスタが残る計算）。
  コルーチンか否かに関係なく同じ上限で当たる。`if^` だけ・`await^` だけなら数百個でも通る。
  → 生成器は状態機械で `next^` を使わない形にして回避した
  → **lhat 側で修正済み**（2026-09-28 18:00 ビルドの lovec で、1 ループに `next^` 120 個でも通ることを確認）。
  生成器の形はそのままでよい（`next^` を使わない形のほうが読みやすさも変わらない）
- **lovec はコンパイル失敗の詳細を出さない**（`Could not compile the program.` だけ）。
  詳細は lhat CLI で、LÖVE を使わない代わりの fighter モジュールに対してコンパイルして得た
- `def^` の中の表の型から Fighter 自身を指すには `Self^^`（1 つ外の型リテラル）。`Self^` だと表の型を指してしまう
- 生成コード 5.5 万行を含めたコンパイル・起動は約 2 秒
