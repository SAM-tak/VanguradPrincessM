# 0038: サポート専用素材を各サポートのフォルダへ配置する

- 日付: 2026-10-05
- ユーザー指示: sharedにあるサポートキャラ専用の画像・音を、キャラごとのimages/soundsへ移す。

## 配置と判定

`tools/fm2k_convert/organize_support_media.py` を追加。共通化後の5体のSkillから画像・音の使用先を集め、1体だけが使用し、かつ本体・デモ・ステージ等のサポート参照以外のSkillに使用が見つからない素材を移す。

キャラの素材一覧に登録されているだけでは本体用とは判定しない。各キャラへ埋め込まれたサポートのライブラリ参照は重複した使用として数えず、実際の命令の参照を調べる。共通HUD補助処理は5体固有の所有者として数えない。

移動先は `assets/supports/<サポート名>/images/NNNN.dds|png` と `sounds/NNNN.wav`。番号は共通素材一覧（ゆい基準）の元番号。同じファイルを複数の番号で参照している場合は最小番号を採用し、素材一覧の番号自体は変更しない。

| サポート | 画像 | 音声 |
| --- | ---: | ---: |
| えこ | 94 | 0 |
| シエラ | 122 | 2 |
| ジュリエット | 86 | 1 |
| かなえ | 116 | 9 |
| ヒルダ | 154 | 2 |
| 合計 | 572 | 14 |

くるみの合体攻撃や既存の補助処理からも使うもの、複数サポートで使用するものは今回の自動移動から除外した。見た目による全素材の所属確定ではなく、現在の参照情報で専用と確認できる586点の整理。

## 参照と変換手順

全画像・音声一覧の該当参照を `asset = "assets/supports/<名前>/..."` へ変更する。共通素材一覧も本体側の元の一覧も更新するので、既存の技番号・素材番号・パレットの対応は変えない。ランタイムの変更は不要。

ファイルをコピーして同一内容を確認した後に一覧を書き換え、全一覧から旧ファイルへの参照が消えたことを確認してからshared側の実体を削除する。異なる内容の既存移動先は上書きしない。

再変換時は以下の順で実行する。

```text
python tools/fm2k_convert/share_assets.py assets --apply
python tools/fm2k_convert/share_supports.py assets --apply
python tools/fm2k_convert/organize_support_media.py assets --apply
```

`--apply` を省くと移動予定の件数のみ表示する。再実行では変更しない。キャラを再変換してshared側に同じファイルが再生成された場合も、既存のサポート配下の実体を照合して同じ配置へ戻せる。
