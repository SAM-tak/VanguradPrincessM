# 0014: BGM のループ

- **日付**: 2026-09-29
- **状況**: ステージの音楽が 1 回で止まっていた（原作はループする）

## 調べたこと

- スクールの BGM は「すく.wav」（ステージの音 #1、22050 Hz ステレオ、95.85 秒）。ステージの #1（スクリプト1）が S ブロックで鳴らす
  （1 ラウンド目の開始時と、システム変数 139 が 0 に戻ったとき）。ステージの「BGM」設定は nosound.wav で使われていない
- **ループポイントはない**:
  - WAV に `smpl` チャンクがない
  - `iwep` / `iwem` チャンクは、波形編集ソフト「Sound it! 3.0」の編集情報（カーソル位置、マーカー 0 個）
- データ上もループの指定はない: 全キャラ・ステージ・システムの音の `endlessLoop` は偽、CDDA も使っていない
- 曲の作り: 先頭のサンプルからいきなり全音量で始まり、最後の約 1.5 秒でフェードアウトして無音で終わる
  （RMS: 95.0 秒 0.028、95.8 秒 0.002）。末尾は途中のどこともつながらない（相互相関 0.1）
  → **ファイル全体を頭から繰り返す単純ループ**の作り

## 決定

- ステージのスクリプトが鳴らす音はファイル全体でループ再生する（`Fighter.loopSounds`、ステージのレイヤーで真）
- 長いので `stream` で読む（キャラの効果音は今までどおり `static`）
- 同じ音を S で鳴らし直したら、頭から（今までどおり止めてから鳴らす）
- 原作のエンジンがどの条件でループさせているか（ステージの音だけか、長さか）は資料からは分からなかった。見つかったら合わせる

## 確認

- 再生中に 95 秒へ飛ばし、約 5 秒後も再生中で、ファイルの 4.5 秒目にいる（末尾から頭へ戻った）
