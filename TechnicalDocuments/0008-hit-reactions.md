# 0008: 相手の反応 — ヒット・ガード・ダメージ・ヒットストップ

- **日付**: 2026-09-28
- **状態**: 練習相手（2 体目のゆい）が、当たればやられ技、ガードすればガード技に移り、体力が減る

## 仕組み（Armonte/wanwan の `docs/editor/hit_junction_system.md` より。読んで理解したのみ）

3 段になっている:

1. **反応の一覧**（ゲーム全体で共通、最大 200）— 「ヒット 弱パンチ 立ち」「ガード 強パンチ しゃがみ」などの名前だけの表。番号 0 は「なし」
2. **キャラごとの表**（`.player` の hitJunctionsSkills）— 反応番号 → そのキャラの**やられ技**と**ヒットスパーク（エフェクト）の技**
3. **攻撃側の R ブロック** — 相手の姿勢（立ち / しゃがみ / 空中）× ヒット / ガードの 6 通りの反応番号

当たったら: 攻撃側の R で反応番号を決め → **受ける側の**表で自分のやられ技を引いて始める。
同じ「弱パンチ立ちヒット」でも、キャラごとに自分のやられ絵で反応する。

生成器は表を `install` に `reactsWith(me, 反応番号, やられ技, スパーク)` として書き出す。

## ガードの規則（データから）

- **R のガード欄 = ガードしている相手が受ける反応**。
  **ガード欄がヒット欄と同じ番号なら、その姿勢ではガードできない。**
  - ゆいの弱キック（#213）: ヒット (1, 4, 5) / ガード (**1**, 76, 5) → 立ちガード不可 = **下段**
  - 空中弱パンチ（#216）: ヒット (6, 7, 5) / ガード (78, **7**, 77) → しゃがみガード不可 = **中段（飛び込み）**
- FA の `guardFail` はガード不能
- ガードは「後ろを押していて、自由に動ける状態（立ち・歩き・しゃがみ・ジャンプ中など）」
- ガードされた攻撃はダメージなし。攻撃側の DS「defending」が発火する

## ヒット

- ダメージ = FA の威力 × FD の被ダメージ率 / 100
- 受ける側は攻撃側の方を向き、やられ技を「エンジンが始める」形（`begin`）で始める
- 攻撃側: C Hit の窓が開く、DS「attacking」が発火する
- 1 つの攻撃判定は 1 回だけ当たる（当たったら攻撃側の判定を消す。次の FA ブロックで再び出る）
- **ヒットストップ**: PS ブロック（攻撃側・相手の停止フレーム）を覚えておき、当たった瞬間に両者をその間止める
  → **誤り（2026-09-29 訂正）**: PS は「その場で自分と相手を止める」命令。ヒットストップは、やられ技の中の PS が攻撃側を止めて作る（0013）

## 確認（キー操作の自動テスト）

- 弱キック → 相手 #47「ヒット 弱パンチ 立ち」、体力 1000 → 980
- 弱斬り（B）→ 相手 #62「ヒット 強パンチ 立ち」、体力 → 933
- 立ちガード中の相手に弱キック → **ヒット**（下段）
- 立ちガード中の相手に B → ガード（#187「ガード 強パンチ 立ち」、ダメージなし）
- しゃがみガード中の相手に弱キック → ガード（#183「ガード 弱パンチ しゃがみ」）

## 操作

- G: 練習相手のガードを切り替え（なし → 立ちガード → しゃがみガード）
- 画面上部に体力バー（仮）
