# 0024: 試合中の上下入力フラグを消費する

- **日付**: 2026-10-04

`keypressed` は画面にかかわらず `upPressed` / `downPressed` を立てる。
タイトルとキャラ選択では毎 tick 消していたが、試合中は `pressed` しか消していなかった。
そのため試合中の下入力が残り、キャラ選択へ戻った最初の tick に、選択中の 1P が「ゆい」から「はるか」へ移動していた。上下両方が残った場合も下が優先される。

試合中も `control(me, ...)` の直後で上下フラグを消す。試合中の移動は `love.keyboard.isDown` を使うため、この変更で押し続けによる移動は変わらない。試合終了による `toSelect` より前に消すので、選択画面への持ち越しを防げる。

確認: 入力処理と遷移順をコード上で確認。実機での試合終了後の動作は未確認。
