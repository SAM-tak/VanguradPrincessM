# 0025: 取得ラウンドマークの更新タイミング

- **日付**: 2026-10-04

原作での動作（ユーザー確認）:

- 決着時は新しく取得したマークだけが取得アニメーションを再生し、取得済みマークは表示を維持する。
- 次ラウンド開始時は取得済みマークも一旦消え、取得アニメーションを再生して再出現する。

以前の `src/round.lh` は決着時に `placeMarks` で全マークを作り直し、次ラウンド開始時には作り直していなかった。

決着時は `awardMark` で勝者の新規取得スロットだけを #55 ON に置き換える。配列は各取得数について 1P / 2P の順なので、インデックスは `2 * (wins - 1) + side`（side は 0 / 1）。既存マークと相手のマークは同じオブジェクトを保ち、引き分けでは変更しない。

次ラウンドの start へ移る際に `placeMarks` を呼び、現在の取得数に応じて #55 ON / #56 OFF を最初から実行する。新しいマークは画像未設定から始まり、表示・待ち時間・取得演出は元のシステムスクリプトに任せる。

検証: `lovec --compile -o build/round-mark-check main.lh` 成功（10 units）。両側のスロット計算と決着・引き分け・次ラウンドの呼び出し経路をコード上で確認。実機での見た目と原作とのフレーム単位のタイミング比較は未実施。
