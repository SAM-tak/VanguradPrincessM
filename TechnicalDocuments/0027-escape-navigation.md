# 0027: ESCで前の画面へ戻る

- **日付**: 2026-10-04

ユーザー指定により、ESCの即終了を画面別に変更。

- 起動演出・タイトル静止画: 終了。
- モードセレクト: タイトル静止画へ戻る。スクロールは再生せず、フラッシュと入力待ちから開始。音声は再生しない（0026の音声仕様変更）。
- キャラクターセレクト: 選択確定状態にかかわらずモードセレクトへ戻る。
- 試合中: 何もしない。ポーズ画面は未実装。

`main.lh` の `goBack` が音声停止・上下と決定入力の消去・画面アリーナの解放を行う。キャラクター選択で既に対戦素材を先読み中なら、match と select の両アリーナを解放する。`vp.sprite.cancelAhead` で残りの先読みも中止し、遷移先に素材を読み込んでしまうのを防ぐ。戻る際にシステム変数をクリアする。

ESCのキーリピートは無視し、押し続けによる連続遷移・終了を防ぐ。

検証: ゲーム全体のコンパイル成功。一時実行ハーネスで実際の `main.keypressed` / `update` を呼び、キャラ選択→モード→タイトル→モードの往復、リピート無視、先読み中の select / match → title の解放と読み込みキューが空になることを確認。ハーネスは削除済み。試合中の無処理・タイトルでの終了は分岐をコード上で確認。
