# 0117: VS対戦後のサポート選択の復元

2026-10-08。

main.toSelectでシステム変数142/143をキャラセレ初期化前に保存し、キャラのカーソル復元後にSelect.restoreSupportへ渡す。パレットと未確定状態は引き継がない。

顔グラの#25/#26は初期化時にサポートを101へ戻し、左右入力の行き先も現在の実行位置に依存する。値だけを戻すのではなく、顔グラ初期化後に、指定サポート値を設定する既存のV命令へ入り直す。位置は実データから検索し、キャラ別のブロック番号を固定しない。通常サポートはその枝で矢印も更新する。

ユーザー指定により、隠しヒルダ105だけは復元せず、初期化時のえこ101へ戻す。通常4サポートは前回の選択を復元する。

2P顔グラは確定判定に134を使用するため、Side.confirmFlagは2Pでは134も更新する。カーソルの確定アニメーションが変数を書き込む順番に依存せず、そのフレームの決定を顔グラへ伝える。

## 確認

全10キャラ×5サポートを両サイドで検証。ヒルダのみえこへ戻り、通常4種は維持されること、放置・決定後も値が変わらずパレットはデフォルトであることを確認。build/support-select-default.logに全10行PASS。
